# 余料仓库

本地单用户电子元件库存管理软件，中文界面。支持搜索元件、登记库存流水、保存电路 BOM、设置制作计划、整板领料和 JSON 备份恢复。

桌面版使用 Swift + AppKit 提供 Mac 窗口、菜单和文件面板，窗口内的界面使用 HTML/CSS/JavaScript。库存规则由 Python 处理，数据保存在 SQLite 中。打包后的应用自带 Python，日常使用只需双击 `余料仓库.app`。

## 功能

- 按名称、型号、立创 C 编号和封装查找元件，记录数量和库位。
- 登记采购、收货、领用、归还、焊坏、损耗和盘点，保留操作历史。
- 为多个项目保存 BOM 和计划数量，计算预留、缺料和配齐能力。
- 整板领料一次检查、一次提交；缺料时整笔不扣，重复请求不重复扣料。
- 本地持久化，支持导出备份、恢复前预览和恢复校验。
- 配置兼容 OpenAI Chat Completions 的 API，通过自然语言查库存、准备操作；修改账本须先核对明细并确认。

具体操作见 [使用说明](使用说明.md)，数量含义和边界见 [需求与业务规则](需求与业务规则.md)。

## 从源码运行

### Mac 桌面版

当前构建目标为 **Apple Silicon Mac，macOS 13 或更新版本**。需要 Swift 工具链（Xcode Command Line Tools）和 [uv](https://docs.astral.sh/uv/)。在项目目录执行：

```sh
./script/build_and_run.sh
```

脚本会创建构建环境、安装固定版本的打包依赖、生成本目录的 `余料仓库.app` 并启动。之后可直接双击应用，也可将其移到“应用程序”文件夹。

仅构建、不启动：

```sh
./script/build_and_run.sh --build-only
```

此仓库提供源码，不包含打包后的应用或 Apple 开发者公证。脚本使用本机临时签名。

### 开发调试

库存服务仅依赖 Python 标准库。使用 Python 3.9 或更新版本，在项目目录执行：

```sh
python3 app.py --open
```

默认打开 `http://127.0.0.1:8765`，调试账本位于 `app_data/warehouse.sqlite3`。终端按 Control+C 停止。桌面版使用独立的数据目录，日常请固定使用同一种入口，避免两份账本分别登记。

## 初始化数据与库存口径

`data/seed.json` 是实际项目的初始化资料，不是演示数据。只在空仓库中导入一次；`data/expected-results.json` 用于核对计算。原始 Excel、CSV 是同源参考副本，不参与初始化，也不随源码发布。

这批资料的快照日期为 2026-10-22：

| 项目 | 初始值 | 含义 |
| --- | ---: | --- |
| 元件种类 | 16 | 已记录的物料 |
| 采购数量 | 675 | 采购记录，最终订单仍待复核 |
| 待领预留 | 180 | 五块跑马灯 155 个、一块 STM32 八路灯板 25 个 |
| 预计自由余料 | 495 | 按采购记录扣除计划后的预测 |
| 实物库存 | 待点数 | 16 种元件均未登记实收 |

`receivedCumulative: null` 表示没有点数记录，与确认收到 0 个不同。采购不会自动增加实物库存。预留不会扣实物，整板领料才扣减实物并释放对应预留。测试中模拟到货的数据只写入临时仓库。

## AI 接入

在应用侧栏“AI 助手 → AI 设置”填写接口地址、模型名和密钥。接口须兼容 Chat Completions，模型须支持工具调用；也支持本机无鉴权接口。

AI 先生成待确认操作单，本地程序校验元件身份、数量和库存规则，用户确认后再一次保存。账本发生变化后旧操作单不能直接执行，同一操作单重复确认不会重复记账。

密钥默认只在本次运行保留；桌面版可选择保存在 macOS 钥匙串。AI 会将问题和所需库存资料发送到用户配置的接口，未配置 AI 时仍可手动使用。真实模型效果取决于所选服务；自动测试使用明确标注的本地模拟接口，不能替代真实服务验证。

## 数据保存与备份

桌面版数据位于 `~/Library/Application Support/余料仓库/`，可通过“文件 → 打开数据文件夹”查看：

- `warehouse.sqlite3`：库存账本和历史。
- `ai.sqlite3`：AI 对话和待确认操作单。
- `ai-settings.json`：接口地址、模型等设置，不存 API 密钥。

使用界面的“备份与恢复”导出库存 JSON。恢复会替换当前仓库，并保存恢复前安全备份。库存 JSON 不含密钥、AI 设置或对话；如需备份整个数据目录，先退出应用再复制。

账本、凭据、对话、备份及构建产物不提交到 GitHub。发布源码不会上传已有的本机库存记录。

## 验证与代码结构

运行全部自动测试：

```sh
python3 -m unittest discover -s tests -v
```

测试覆盖初始化口径、未知与零实收、预留转领料、缺料时不部分扣减、重复请求、历史 BOM、持久化与备份恢复，以及 AI 操作预览、确认、失效和失败回滚。

| 路径 | 职责 |
| --- | --- |
| `warehouse.py` | 库存规则、事务和 SQLite 保存 |
| `app.py` | 本机 HTTP 接口 |
| `desktop_server.py` | 桌面服务启动、旧账迁移和退出清理 |
| `ai_assistant.py`、`ai_credentials.py` | AI 接口、操作单和凭据管理 |
| `native/` | Mac 窗口、菜单、文件面板和钥匙串辅助程序 |
| `web/` | 中文操作界面 |
| `data/` | 唯一初始化数据与预期结果 |
| `tests/` | 使用临时仓库和模拟接口的自动测试 |
| `script/` | 构建和图标生成 |

当前范围为本机单用户，每种元件一个文字库位。不含云同步、账号、成本核算、自动采购、EDA 解析或撤销整板领料。
